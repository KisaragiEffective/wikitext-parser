# Another Approximate parser for wikitext

[![Version](https://img.shields.io/crates/v/wikitext-parser2.svg)](https://crates.io/crates/wikitext-parser)
[![Downloads](https://img.shields.io/crates/d/wikitext-parser2.svg)](https://crates.io/crates/wikitext-parser)
[![](https://docs.rs/wikitext-parser2/badge.svg)](https://docs.rs/wikitext-parser2)

Parse wikitext into an approximate representation, parsing some features of wikitext correctly, while being mostly incorrect for erroneous wikitext.
